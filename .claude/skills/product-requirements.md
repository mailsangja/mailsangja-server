# Mailbox Product Requirements

## 1. Idea Definition
- **Problem**: Difficulties in drafting emails and managing the inbox.
- **Solution**: An AI agent service that assists with email drafting and management.
- **Target**: Users who actively use email.
- **Stakeholder**: Google, Naver, LLM Providers, Users.
- **Value**:
  - Users: Easy email drafting and inbox management.
  - Platforms/LLMs: User acquisition and token-based revenue generation.
- **POP (Point of Parity)**: Email viewing, drafting, deleting, archiving, attachment management, email tracking.
- **POD (Point of Difference)**: Multi-account/vendor inbox integration, RAG and LLM-based personalized email categorization and drafting automation.

## 2. Personas
- **Persona 1 – Mail Sender**: Wants quick and easy email drafting/sending, transparent read receipts, and a secure sending experience.
- **Persona 2 – Mail Receiver**: Wants quick access to received emails, efficient categorization (important/unimportant), and smooth communication.
- **Persona 3 – Service Admin**: Responsible for service quality management, data-driven policy establishment, incident response, and sending announcements.

## 3. User Journeys
- **Sender**: Access web -> Set recipient -> Enter email subject -> Review AI suggestions -> Complete content -> Send -> View AI auto-review popup -> Check tracking.
- **Receiver**: Receive email notification -> Access client -> Check AI auto-labeling -> Review important email summaries -> Check AI-recommended replies -> Edit and send.
- **Admin**: Access dashboard -> Monitor status -> Detect anomalies -> Send announcements -> Manage subscriptions/usage.

## 4. Epics & User Stories

### Epic 1: User Authentication and Mail Account Management
* User Story 1.1: As a service user, I want to sign up and log in to the service.
* User Story 1.2: As a sender and receiver, I want to integrate multiple Gmail accounts into the service → To centrally manage all emails in a single unified inbox without opening multiple tabs.
* User Story 1.3: As a sender and receiver, I want to set and switch between default sending/receiving accounts among the integrated accounts.

### Epic 2: Unified Mail Inbox
* User Story 2.1: As a receiver, I want to receive emails from multiple accounts and gather them in one place.
* User Story 2.2: As a receiver, I want to see at a glance which account an email came from.
* User Story 2.3: As a receiver, I want to mark emails as read.
* User Story 2.4: As a receiver, I want to delete unnecessary emails.
* User Story 2.5: As a receiver, I want to view consecutive emails as a single Thread.
* User Story 2.6: As a receiver, I want to receive real-time push notifications when a new email arrives.

### Epic 3: Sending Mail
* User Story 3.1: As a sender, I want to send an email using the account of my choice.
* User Story 3.2: As a sender, I want to attach files and send an email.
* User Story 3.3: As a sender, I want to send an email in Markdown format.
* User Story 3.4: As a sender, I want to check the history of emails I have sent.
* User Story 3.5: As a sender, I want to reply to an email I previously received.
* User Story 3.6: As a sender, I want to specify multiple recipients, CC, and BCC to send an email.

### Epic 4: Automated Mail Categorization and Management
* User Story 4.1: As a receiver, I want to manually add labels and rules.
* User Story 4.2: As a receiver, I want to gather and view emails containing a specific label in one place.
* User Story 4.3: As a receiver, I want the LLM to automatically suggest labels and rules.
* User Story 4.4: As a receiver, I want to remove a specific label.
* User Story 4.5: As a receiver, I want to change the rules of a specific label.
* User Story 4.6: As a receiver, I want to reclassify past emails according to the labeling rules.
* User Story 4.7: As a receiver, I want to change real-time push notification settings based on label configurations.
* User Story 4.8: As a receiver, I want to group multiple labels together and view them.

### Epic 5: AI-Assisted Mail Drafting
* User Story 5.1: As a sender, I want to input my purpose in prompt format into the compose window to check the email subject and draft generated by AI.
* User Story 5.2: As a sender, I want the LLM to run in the background upon clicking the send button, checking for typos, missing attachments, and contextual appropriateness, and alerting me via a popup.

### Epic 6: AI-Assisted Mail Reply Processing
* User Story 6.1: As a receiver, I want to be able to click on 2~3 reply options suggested by AI based on the received email content and previous text context.
* User Story 6.2: As a receiver, I want to freely edit the text of the selected recommended reply in the editor, apply formatting, and finally send it.

### Epic 7: Service Monitoring and Incident Response
* User Story 7.1: As an admin, I want to receive immediate warning alerts via the admin Discord channel when anomalies occur, such as server downtime or external mail vendor API integration failures.
* User Story 7.2: As an admin, I want to immediately distribute an in-web announcement popup to affected user groups or all users during system maintenance or incident remediation.
